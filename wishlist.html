Облако через GitHub Gist

Как подключить (один раз, 2 минуты):
  1. Открой github.com/settings/tokens/new
  2. Название — любое. Поставь галочку gist.
  3. Нажми Generate token (внизу страницы).
  4. Скопируй токен — он показывается один раз.
  5. Вставь его сюда ↓ и нажми «Подключить».
⚠️ Токен хранится только в этом браузере. Если сомневаешься — создавай fine-grained token с доступом только к Gists. Отозвать можно в любой момент в настройках GitHub.
